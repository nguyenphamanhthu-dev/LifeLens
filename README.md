# LifeLens – Smart Visual Assistant

LifeLens is an Android application that uses
on-device OCR to recognize text from images
and turn it into useful actions.

## Tech Stack
- Kotlin
- Jetpack Compose
- MVVM Architecture
- ML Kit Text Recognition
- Room Database
- CameraX
- Android AlarmManager

## Features
- Camera and gallery text scanning
- Smart action detection
- Event reminders and notifications
- Scan history
- Maps, links and phone integration
